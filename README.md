# Музыкальный каталог

Музыкальный веб-сайт для знакомства с исполнителями, поиска альбомов и сохранения любимой музыки.

## О проекте

Сайт представляет собой интерактивный музыкальный каталог с информацией об исполнителях, альбомах и композициях.

Пользователи могут просматривать музыкальные релизы, искать исполнителей, оставлять отзывы и получать рекомендации.

## Функциональность

- Главная страница с популярными исполнителями и музыкальными новинками.
- Каталог исполнителей с поиском.
- Персональные страницы исполнителей с биографиями, фотографиями и альбомами.
- Каталог альбомов с поиском и фильтрацией по жанрам.
- Подробные страницы альбомов со списками композиций.
- Оценки и отзывы пользователей.
- Добавление исполнителей и альбомов в избранное.
- Генератор случайного альбома.
- Подбор альбомов по настроению.
- Адаптивный интерфейс для разных размеров экранов.

## Технологии

- HTML5 — структура страниц.
- CSS3 — оформление и адаптивная вёрстка.
- JavaScript — интерактивные функции сайта.
- LocalStorage — сохранение избранного и отзывов в браузере.

## Дизайн

Сайт выполнен в минималистичном тёмном стиле Black Minimal.

Основные особенности интерфейса:
- Чёрная и графитовая цветовая палитра.
- Карточки исполнителей и альбомов.
- Плавные анимации при наведении.
- Удобная навигация.
- Адаптация под мобильные устройства.

## Запуск проекта

1. Склонировать репозиторий:

```bash
git clone https://github.com/godspeedglory/my_site_FIBR.git
```

2. Открыть папку проекта в Visual Studio Code.

3. Запустить `index.html` через расширение Live Server.

Проект не требует установки дополнительных библиотек.

## Хранение данных

Избранные исполнители, альбомы и отзывы сохраняются локально в браузере с помощью LocalStorage.

Серверная часть и база данных не используются.
